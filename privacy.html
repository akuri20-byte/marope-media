プライバシーポリシー

最終更新日：2026年10月26日

「marope-studio」は、まろぺとぽむぎの運営者が、自分自身のTikTok・YouTubeチャンネル・Instagram・Threadsに自作の4コマ動画と画像を投稿するためだけに使う、運営者専用の仕組みです。

取得する情報

運営者自身のアカウントへの投稿に必要な認証情報（アクセストークン）だけを使います。利用者や視聴者の個人情報は取得・保存しません。

使い方

YouTube API サービスは、運営者のチャンネルに動画をアップロードし、投稿済みの動画を確認するためだけに使います。データを第三者に提供・販売することはありません。

保存と削除

認証情報は暗号化された保管場所（GitHub Secrets）にだけ保存します。Googleアカウントの「サードパーティのアクセス」からいつでも連携を解除できます。

YouTube API サービスの利用には YouTube利用規約 と Googleプライバシーポリシー が適用されます。

Privacy Policy (English)
